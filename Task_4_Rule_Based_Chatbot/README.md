# Rule-Based Interactive Terminal Chatbot

## Project Overview
This project is a rule-based chatbot developed using Python. It interacts with users through the terminal and responds to common customer support queries.

## Features
- Greeting and welcome messages
- Business hours information
- Product FAQ responses
- Return and refund information
- Case-insensitive input handling
- Keyword and pattern-based intent recognition
- Default response for unknown queries
- Exit commands such as bye, exit, and quit

## Technologies Used
- Python 3
- JSON
- Regular Expressions
- String Handling

## Project Structure
Rule_Based_Chatbot/
├── chatbot.py
├── sample_faq.json
└── README.md

## How to Run
1. Make sure Python is installed.
2. Open the project folder in a terminal.
3. Run the following command:

python chatbot.py

## Sample Interaction
User: Hi
Bot: Hello! Welcome to our customer support chatbot.

User: What are your business hours?
Bot: Our business hours are Monday to Saturday, 9 AM to 6 PM.

User: bye
Bot: Goodbye!
